--CONTAINER--
Create container -> docker run -d --name my-local-cloud -p 4566:4566 localstack/localstack:3.4.0
Create awslocal variable -> doskey awslocal=aws --endpoint-url=http://localhost:4566 $*
Check variable -> awslocal s3 ls
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

--S3--
Create Bucket -> curl -X PUT "http://localhost:4566/first-bucket"
Remove Bucket -> awslocal s3 rb s3://first-bucket
Upload CSV -> curl -X PUT -H "Content-Type:text/csv" --data-binary "@users.csv" "http://localhost:4566/first-bucket/users.csv"
Verify Upload -> curl -X GET "http://localhost:4566/first-bucket/users.csv" (Read Content) OR curl -X GET "http://localhost:4566/first-bucket (List bucket contents)
Security -> Access Controls [Block Public Acces, IAM policies, Bucket Policies], Encryption [At Rest, In Transit], Data Protection [Bucket Versioning, Object Lock], Monitoring [Cloudtrail, Guard Duty]
s3 Bucket Policy -> {
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "AllowPublicRead",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-bucket-name/*",
      "Condition": {
        "IpAddress": {
          "aws:SourceIp": "192.168.1.0/24"
        }
      }
    }
  ]
}
s3 Versioning: Uploading files(overwriting), Deleting files(Delete Markers)
s3 Replication: Cross Region Replication, Same Region Replication, RTC
s3 Storage Class: Standard(Daily Active Usage), Intelligent Tiering(Unpredictable), Standard IA(Mahine mai 1-2 baar), Onezone IA(Mahine mai 1-2 baar + Non critical data), Glacier Flexible(Backup data), Glacier Deep Archive(pta nhi kb chahiye)
