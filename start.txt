--CONTAINER--
Create container -> docker run -d --name my-local-cloud -p 4566:4566 localstack/localstack:3.4.0
Create awslocal variable -> doskey awslocal=aws --endpoint-url=http://localhost:4566 $*
Check variable -> awslocal s3 ls
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

--S3--
Create Bucket -> curl -X PUT "http://localhost:4566/first-bucket"
Remove Bucket -> awslocal s3 rb s3://first-bucket
Upload CSV -> curl -X PUT -H "Content-Type:text/csv" --data-binary "@users.csv" "http://localhost:4566/first-bucket/users.csv"
Verify Upload -> curl -X GET "http://localhost:4566/first-bucket/users.csv" (Read Content) OR curl -X GET "http://localhost:4566/first-bucket (List bucket contents)
